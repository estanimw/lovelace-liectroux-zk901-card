Restores the community map card frontend and connects it to the existing ZK901 integration.

- Restores the original map layout, touch navigation, zoom controls, icon menus, status tiles and notifications.
- Displays telemetry-derived routes, estimated coverage and robot position through a locally generated SVG map with automatic coordinate alignment.
- Moves persistent zone editing, route history, layers and diagnostics into secondary panels.
- Preserves multi-zone selection, draft protection, conflict handling and explicit save confirmation.
- Adds keyboard accessibility, theme-aware contrast and isolated component names for coexistence with the upstream card.
- Retains the existing local control, autonomous route collection, storage and update behavior.
