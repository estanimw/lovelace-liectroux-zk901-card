# Variables CSS

La tarjeta de la Liectroux ZK901 usa variables del tema de Home Assistant y estas variables propias, que pueden redefinirse en la tarjeta o en su contenedor:

```css
--zk-card-border
--zk-map-bg
--zk-zone-normal
--zk-zone-depth
--zk-zone-forbid
```

Los tipos de zona también se distinguen con patrones de línea y etiquetas; el color no es la única señal.
